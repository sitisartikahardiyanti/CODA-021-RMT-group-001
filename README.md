# Deskripsi
Indonesian JobStreet Salary & Hybrid Recommendation Dataset merupakan dataset yang berisi informasi gaji dari lowongan pekerjaan di JobStreet Indonesia yang telah diagregasi. Dataset ini dikembangkan melalui pendekatan web scraping dan sistem rekomendasi hybrid untuk mengidentifikasi rata-rata gaji berdasarkan posisi pekerjaan, perusahaan, dan wilayah di Indonesia.

Dataset ini dapat digunakan untuk berbagai kebutuhan analisis dan pemodelan, seperti:
Prediksi gaji berdasarkan karakteristik pekerjaan.
Analisis pasar tenaga kerja di Indonesia.
Sistem rekomendasi karier bagi pencari kerja.
Analisis kompensasi dan HR berbasis data.
Analisis perbedaan gaji berdasarkan posisi, perusahaan, dan lokasi.

Secara keseluruhan, dataset ini dapat memberikan gambaran mengenai pola dan variasi gaji pekerjaan di Indonesia serta mendukung pengambilan keputusan yang berbasis data dalam bidang karier dan sumber daya manusia.
